## 2. Qué permite hacer esta web

La web permite explorar información sobre talleres y materiales. Esta versión no ofrece registro de clientes, carrito, cobro, reserva de cupos ni inscripción automática.

El estado actual es de demostración: los textos, ilustraciones, fechas, precios y disponibilidad identificados como ejemplos no constituyen una oferta comercial real. Las ilustraciones conceptuales no representan fotografías de productos, trabajos o personas del negocio.

El contacto aparece como «Contacto por confirmar». Mientras permanezca así, las acciones internas llevan a la sección de contacto y no abren una conversación con AR Crafts.

## 4. Información de talleres y materiales

«Consultar precio» significa que la web no informa un importe; no significa que el producto o servicio sea gratuito. «Próxima fecha por confirmar» significa que no se informa una próxima edición confirmada.

Una ficha de material describe una presentación concreta. El catálogo no confirma inventario en tiempo real. Un material identificado como no disponible permite consultar alternativas, sin prometer una fecha de reposición.

Las condiciones confirmadas de una contratación y los derechos que correspondan al consumidor no se modifican por una actualización posterior del sitio. Este texto no excluye la responsabilidad por información comercial incorrecta ni limita las garantías legales aplicables.
